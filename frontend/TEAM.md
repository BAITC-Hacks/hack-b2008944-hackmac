# 👥 РАСПРЕДЕЛЕНИЕ ОБЯЗАННОСТЕЙ КОМАНДЫ (3 УЧАСТНИКА)
## Проект: Модернизация EKT.KZ и Интеллектуальный ИИ-Инженер для хакатона

Проект разработан командой из трех специалистов с четким разделением зон ответственности: **Backend**, **Frontend** и **ИИ-помощник (AI Engineer)**.

---

## 👨‍💻 УЧАСТНИК 1: BACKEND-РАЗРАБОТЧИК (Сервер, API, Архитектура Данных и Склады)

### 🎯 Зона ответственности:
Разработка серверной части на Node.js / Express, проектирование REST API, моделирование каталога электротехнической продукции ekt.kz, реализация складского учета по городам Казахстана и пагинации данных.

### 📁 Ключевые файлы:
1. `server.ts` — Основной серверный файл Express:
   - Эндпоинт `GET /api/products` — серверная фильтрация по категории, бренду, номиналу тока (А), отключающей способности (кА), числу полюсов, наличию на складе конкретного города, пагинация (page 1, 2) и сортировка.
   - Эндпоинт `GET /api/products/:id` — получение детальной информации о товаре.
   - Эндпоинт `GET /api/cities` — список филиалов и адресов складов (Астана, Алматы, Шымкент, Караганда и др.).
   - Эндпоинт `POST /api/chat` — серверная обработка запросов к ИИ-консультанту с системным промптом инженера.
   - Эндпоинт `GET /api/health` — проверка работоспособности сервера.
2. `src/data/mockProducts.ts` — Структура базы данных и полный датасет товаров:
   - Реальные позиции каталога ekt.kz: автоматические выключатели Legrand серии DRX125 и DRX250, реле контроля фаз и защиты насосов Schneider Electric RM35 / RM17, светильники OPPLE, диф. автоматы и модульное оборудование.
   - Складские остатки с разбивкой по городам Казахстана (Астана: ул. Бейсекбаева 24/1, Алматы: пр. Райымбека 169А, Шымкент, Караганда).
3. `src/types/index.ts` — TypeScript интерфейсы и типы данных:
   - `Product`, `StockInfo`, `CityInfo`, `FilterState`, `ChatMessage`, `CartItem`.
4. `src/services/api.ts` — Клиентский слой сетевых запросов:
   - Взаимодействие с бэкенд API с безопасным fallback в случае автономного режима.

## 🎨 УЧАСТНИК 2: FRONTEND-РАЗРАБОТЧИК (Интерфейс, Дизайн, UX, Каталог и Корзина)

### 🎯 Зона ответственности:
Создание современного адаптивного интерфейса интернет-магазина электротехники в фирменном стиле EKT.KZ, верстка компонентов, мобильная оптимизация, реализация каталога, фильтров, корзины с расчетом НДС 12% и генерацией Коммерческих Предложений.

### 📁 Ключевые файлы:
1. `src/App.tsx` — Корневой компонент приложения:
   - Управление глобальным состоянием (выбранный город, корзина, фильтры, открытые модальные окна, уведомления toast).
2. `src/components/Header.tsx` & `src/components/Footer.tsx`:
   - Навигация по разделам, переключатель филиалов/складов городов Казахстана.
   - Поисковая строка в реальном времени, счетчик корзины, контакты складов.
3. `src/components/HeroBanner.tsx`:
   - Презентационный баннер с интерактивными кнопками быстрого перехода к калькулятору и каталогу, бейдж команды из 3 участников.
4. `src/components/CatalogSection.tsx` & `src/components/ProductCard.tsx`:
   - Два режима отображения: современная плиточная сетка и табличный вид для снабженцев и B2B.
   - Фильтры по параметрам (Бренд, Ток, Полюса, Наличие в выбранном городе).
   - Индикация наличия на складе с точным адресом (например, "В наличии на складе в Астанае: ул. Бейсекбаева 24/1").
   - Пагинация каталога (Page 1, Page 2).
5. `src/components/ProductDetailModal.tsx`:
   - Карточка товара с подробными техническими характеристиками и остатками по всем городам РК.
6. `src/components/CartModal.tsx`:
   - Интерактивная корзина с подсчетом суммы, выделением НДС 12%, функцией формирования и печати официального Коммерческого Предложения (КП) для ТОО/ИП с реквизитами EKT.KZ.
7. `src/components/ElectricalCalculatorModal.tsx`:
   - Инженерный калькулятор перевода мощности (кВт) в ток (Амперы) с мгновенным применением фильтра в каталоге.

## 🤖 УЧАСТНИК 3: AI-ИНЖЕНЕР (ИИ-Помощник, Промпт-инжиниринг, ПУЭ РК, Голос)

### 🎯 Зона ответственности:
Разработка ядра интеллектуального консультанта "ЭКТ Инженер", создание базы инженерных знаний по ПУЭ Республики Казахстан, промпт-инжиниринг для Google Gemini API, клиентский fallback с экспертными правилами, голосовой ввод и синтез речи.

### 📁 Ключевые файлы:
1. `src/components/AIConsultantChat.tsx`:
   - Интерфейс диалога с ИИ-консультантом.
   - Быстрые инженерные сценарии ("Вводной автомат на 30 кВт", "Защита глубинного насоса 5.5 кВт", "Диф. автомат для розеток").
   - Интерактивные карточки рекомендованных товаров прямо внутри сообщений чата с возможностью в 1 клик добавить в корзину или открыть детальные характеристики.
   - Голосовой ввод вопросов (Web Speech API) и синтез ответа голосом (SpeechSynthesis).
2. `server.ts` (Блок Gemini AI):
   - Интеграция SDK `@google/genai` (модель Gemini 3.8 Flash).
   - Системный промпт инженера EKT с каталогом товаров, правилами расчета пусковых токов и рекомендацией сертифицированных брендов.
3. `src/services/aiConsultant.ts` — Автономная экспертная система (работает даже без API-ключа):
   - Расчет тока по формулам ПУЭ РК:
     * Для однофазной сети 220В: $I = \frac{P}{220 \cdot \cos\varphi}$
     * Для трехфазной сети 380В: $I = \frac{P}{\sqrt{3} \cdot 380 \cdot \cos\varphi}$
   - Алгоритм подбора сечения медного кабеля (ВВГнг-LS) в зависимости от тока.
   - Автоматический подбор силовых автоматов Legrand серии DRX125 / DRX250 и реле контроля насосов Schneider Electric RM35BA10 / RM17.

## 🚀 КАК ОТКРЫТЬ И ЗАПУСТИТЬ ПРОЕКТ В VISUAL STUDIO CODE

Проект полностью настроен для работы в **VS Code**. Для локального запуска выполните следующие шаги:

### Шаг 1. Откройте папку проекта в VS Code
- Запустите Visual Studio Code.
- В верхнем меню выберите: `File` ➔ `Open Folder...` (или нажмите `Ctrl + K`, затем `Ctrl + O`).
- Выберите корневую папку данного проекта.
- Либо в терминале вашей операционной системы перейдите в папку проекта и введите:
  ```bash
  code .
  ```

### Шаг 2. Откройте встроенный терминал VS Code
- В верхнем меню VS Code выберите: `Terminal` ➔ `New Terminal`
- Или нажмите горячие клавиши: `` Ctrl + ` `` (тильда / буква ё).

### Шаг 3. Установите зависимости
В терминале VS Code выполните:
```bash
npm install
```

### Шаг 4. Запустите проект в режиме разработки
В терминале VS Code выполните:
```bash
npm run dev
```

### Шаг 5. Откройте сайт в браузере
В терминале появится ссылка:
```
  VITE v6.x.x  ready in ... ms

  ➜  Local:   http://localhost:3000/
```
Нажмите `Ctrl + клик` по ссылке или откройте в браузере адрес:
👉 **http://localhost:3000**
